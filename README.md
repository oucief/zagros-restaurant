# Zagros Restaurant — Official Web Application

A sleek, mobile-first web application for **Zagros Restaurant** (5-7 Bentinck Rd, Radford, Nottingham NG7 4AA, UK), built with **React**, **Tailwind CSS v4**, and **Vite**.

## 🚀 Key Features

1. **Hero Banner:**
   - Highlights 5.0-Star Google review badge (18 reviews)
   - Real-time "Open Daily (11:00 AM – 10:00 PM)" badge with pulse indicator
   - Full Nottingham address with 1-click direction triggers
   - Direct call-to-action buttons: "Call for Takeout", "Explore Menu", and "Find on Maps"

2. **Sticky Mobile Bottom Bar:**
   - **Call for Takeout:** Opens `tel:+441159420088` instantly
   - **Find Us on Maps:** Navigates directly to 5-7 Bentinck Rd on Google Maps
   - **Order Tray Counter:** Shows item count and running total

3. **Menu Showcase (Filterable Tabs & Search):**
   - **Tabs:** "All Items", "Grill & Kebabs", "Rice Dishes & Stews", "Appetizers & Bread", "Drinks & Desserts"
   - Real-time instant search bar (filter by ingredient, dish name, or Kurdish/Arabic title)
   - Tag filters: "Chef's Signature", "Best Seller", "Vegetarian"
   - Authentic dishes with prices in GBP (£), descriptions, allergen notices, and native script titles
   - Interactive modal with dish details, allergen advisory, and portion notes
   - "Add to Takeout" functionality with quantity controls

4. **Interactive Takeout Order Drawer:**
   - Review selected dishes and adjust quantities
   - Special request notes (e.g. extra garlic toum, mild spices)
   - Estimated total calculation
   - 1-Click "Call Kitchen to Place Order"
   - "Copy Order to Clipboard" formatted text for reading over the phone or sending via messaging apps

5. **Charcoal Hearth & Heritage Section:**
   - Explains the Zagros culinary philosophy: hardwood charcoal mangal cooking at high temperatures, 400°C clay tandoor naan, and slow-braised 5-hour lamb shank Qozi.

6. **Trust Badges:**
   - 100% Halal Certified
   - Natural Charcoal Mangal (no gas griddles)
   - Clay Oven Tandoor Naan baked fresh to order
   - Dine-In Comfort & Rapid Takeout Collection

7. **5.0-Star Customer Reviews:**
   - Testimonials from diners highlighting the juiciness of the Kobeda kebabs, tender lamb shank, hot naan, and Kurdish hospitality.

8. **Location & Opening Hours:**
   - Interactive Google Maps embed for 5-7 Bentinck Rd, Radford, Nottingham
   - Daily schedule table (Monday – Sunday: 11:00 AM – 10:00 PM)
   - Travel & parking details (Bentinck Rd parking & public transit routes)
   - Diners' Frequently Asked Questions (Halal certification, takeaway prep time, family dining)

## 🛠️ Technology Stack
- **Framework:** React 19
- **Build Tool:** Vite 8
- **Styling:** Tailwind CSS v4 (`@tailwindcss/vite`)
- **Icons:** Lucide React
- **Typography:** Playfair Display (Serif Display) + Plus Jakarta Sans (Modern UI)

## 📦 Getting Started

### 1. Development Server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 2. Production Build
```bash
npm run build
```
Creates an optimized, production-ready static bundle in the `dist/` directory.

### 3. Preview Production Build
```bash
npm run preview
```

### 4. Code Quality & Linting
```bash
npm run lint
```
0 errors, 0 warnings.
